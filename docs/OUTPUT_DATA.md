# Output Data

> **Last updated**: 2026-09-23

All exports are written to [src/data](../src/data/). Filenames embed
`new Date().getTime()` (milliseconds), so consecutive runs never overwrite
previous results.

## File naming

| Pattern                             | Producer                    | Example                                    |
| ----------------------------------- | --------------------------- | ------------------------------------------ |
| `fialda-<group>-<timestamp>.csv`    | Fialda v2 controller        | `fialda-invested-1790067297646.csv`        |
| `fialda-test-<timestamp>.csv`       | Fialda v2 with `TEST` group | `fialda-test-1790070221577.csv`            |
| `batdongsan-<slug>.json`            | BatDongSan raw snapshot     | `batdongsan-flora-novia.json`              |
| `batdongsan-<slug>-<timestamp>.csv` | BatDongSan cleaned export   | `batdongsan-flora-novia-1790067297646.csv` |

The output directory is created automatically if missing.

## Fialda CSV (pivoted, v2)

Rows are metrics; columns are stock symbols. First column header is `title`.

```csv
title,ACB,ACV,BCM,...
Exchange,HSX,UPCOM,HSX,...
Price Now,22.00,39.60,40.20,...
Price 52W Min,18.71,37.00,33.90,...
Price 52W Max,23.85,64.80,82.27,...
```

- The column order follows the ticker list order in
  [src/constants/stocks.js](../src/constants/stocks.js).
- `"-N-"` separator entries in the ticker lists produce **empty columns**
  between industry groups.

## BatDongSan CSV

One row per listing card:

| Column       | Description                                      |
| ------------ | ------------------------------------------------ |
| `price`      | Listing price, unit stripped (`tỷ` removed)      |
| `area`       | Area in m², unit stripped                        |
| `pricePerM2` | Price per m², unit stripped                      |
| `date`       | Absolute publish date (relative labels resolved) |

The companion `.json` file keeps the **raw** scraped fields before cleanup.

## Consuming the data

- CSV files are UTF-8, comma-separated, generated by `json-2-csv`.
- Empty cells mean the metric was not available for that symbol (or the
  symbol was a `"-N-"` separator).
- To build time series, keep multiple timestamped exports and join on the
  `title` column / listing fields.
